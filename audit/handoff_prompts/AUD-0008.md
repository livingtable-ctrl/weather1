**Evidence (E1):** Confirmed the `if live:` block (`main.py:3759-3790`) has zero `try/except` while the three subsequent paper-side blocks in the same function are each wrapped in `except Exception`. **Recommendation (from the audit):** Wrap the 4 live-protection calls in the same `try/except`-and-log pattern already used for the paper-side checks and `cron.py`'s guard.
